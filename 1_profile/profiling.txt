PHASE 1 — CLI PROFILING
=======================

Project: First-Move Advantage in Online Chess
Dataset: lichess_db_standard_rated_2026-06.pgn.zst
Source:  https://database.lichess.org/standard/lichess_db_standard_rated_2026-06.pgn.zst

Background:
`zstdcat` is used to stream-decompress the file on the fly for every command
below instead of extracting it first, because the decompressed PGN is
~90+ GB and would not fit comfortably alongside everything else on disk.
`time` is placed in front of every command to measure computational cost.

Note on format: this dataset is PGN, not CSV. There is no natural
comma-delimited column to run `cut -d',' -f` / `column -t` against for a
schema peek, so the schema-peek step below uses `cut -d'"' -f2` instead,
which is the direct equivalent for PGN's `[Tag "Value"]` line format —
it isolates the quoted value the same way `cut -d',' -f` would isolate a
CSV column. `column -t` is used further down to pretty-print the top-10
openings table.

Note: `tail` on a streamed pipe cannot seek to the end, so zstdcat has to
decompress the entire 26 GB file for this one command — that is why this is
by far the most expensive command in this profiling pass (~1 hour wall
clock vs. seconds/minutes for everything else). This cost difference is
itself one of the "big data" observations worth calling out on the poster.

SUMMARY (for the poster's "Profiling" section)
--------------------------------------------------
- Compressed size:     26 GB (.pgn.zst)
- Total lines:         1,730,301,832
- Total games:         86,483,328  (> the 50M-row/5GB dataset-size floor)
- Average White Elo:   1643.37
- Most common opening: Queen's Pawn Game (2,294,666 games)
- Most common outcome from the sampled Termination tags: "Normal" (with
  "Time forfeit" a frequent second, expected for bullet/blitz-heavy play)
- Every command above ran in minutes to just over an hour on a single
  laptop core, with no tool ever loading the dataset into memory — this is
  the baseline the Phase 2 breaking-point tests (Excel, pandas) are
  contrasted against.
